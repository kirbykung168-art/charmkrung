# Charmkrung — official website

Single-page brand site for **Charmkrung**, a modern Thai small-plates and wine bar on the 6th floor of a 1950s factory in Charoen Krung / Talat Noi, Bangkok.

Built with **Next.js 14 (App Router)** + **TypeScript** + **Tailwind CSS** + **framer-motion** + **Lenis** smooth scroll. Reservations route to **SevenRooms** — there is no booking system in this codebase.

---

## Quick start

```bash
npm install
npm run dev
```

Open <http://localhost:3000>.

## Editing copy

**All user-facing strings live in `src/lib/content.ts`** — one file. Each entry has an `en` and `th` field. Change copy here and it updates everywhere.

The `BRAND` object at the top holds facts: phone, address, hours, URLs.

## Swapping images

The build ships with **mood-matched placeholder gradients** rather than stock photos — so the design system is visible without pretending we have the owner's photography yet.

To wire in real photos:

1. Drop the file in `public/images/` (e.g. `public/images/hero.jpg`).
2. In `src/components/Hero.tsx`, replace the `<HeroBackdrop />` component with:

```tsx
import Image from 'next/image';
//...
<Image
  src="/images/hero.jpg"
  alt="Charmkrung interior at night"
  fill
  priority
  sizes="100vw"
  className="object-cover"
/>
```

Same pattern in `Menu.tsx` (replace `<DishPlateholder index={i} />`) and `Space.tsx` (replace each tile background with `<Image fill />`).

Recommended sizes:
- Hero: 2400 × 1600
- Dish cards: 1200 × 900
- Space tiles: 1600 × 1200

OG share image: `public/og.jpg` at 1200 × 630.

## EN / TH toggle

Implemented via `<LanguageProvider>` (React context + `localStorage`). The current locale is stored under `charmkrung-locale`. The `<html lang>` attribute updates dynamically.

To add a new locale, add `'zh'` to the `Locale` type in `content.ts`, then fill in `zh` strings for every entry. `LangToggle.tsx` needs a third button.

## Reservations integration

The site **does not handle bookings**. Every "Reserve" button links to:

```
https://www.sevenrooms.com/explore/charmkrungbangkok/reservations/create/search
```

To change the URL: edit `BRAND.reserveUrl` in `content.ts`.

The site also surfaces a LINE link (`BRAND.lineUrl`) and IG DM (`BRAND.instagramUrl`) as secondary contacts.

## SEO

- `<title>` and `<meta>` set in `app/layout.tsx`
- JSON-LD **Restaurant** schema in the `<head>` — gives Google address, hours, geo, telephone, social handles, and the reservations URL as a `ReserveAction`
- `sitemap.xml` and `robots.txt` auto-generated by Next 14's `app/sitemap.ts` and `app/robots.ts`
- All images are `next/image` once swapped in — gives auto-format, lazy loading, correct sizing for Core Web Vitals
- Skip-to-content link in `layout.tsx` for keyboard / screen reader users
- Semantic landmarks (`<main>`, `<nav>`, `<footer>`, `<article>`, `<section>`)

## Deploy to Vercel

1. Push this repo to GitHub.
2. In Vercel: **Add New… → Project → Import** your `charmkrung` repo.
3. Framework preset: **Next.js**. No env vars needed.
4. Click **Deploy**. First build ~90 seconds.

### Custom domain

Once deployed, in the Vercel dashboard:
**Project → Settings → Domains → Add** → enter `charmkrung.com` (or whichever).
Vercel will show DNS records to set at your registrar:
- An `A` record on `@` pointing to `76.76.21.21`, OR
- A `CNAME` on `www` pointing to `cname.vercel-dns.com`

Once DNS resolves, also update `SITE_URL` in `src/app/layout.tsx` + `BASE` in `sitemap.ts` and `robots.ts` from `https://charmkrung.vercel.app` to the new domain so canonical URLs are correct.
